# flat-diagram-style 通用化验证 · 2026-10-13

## 范围与方法

实际运行环境为 macOS、Python 3.12.14、Pillow 12.3.0。执行使用 Codex 随附 Python；没有改动系统 Python 或安装字体。两个独立子代理分别做旧版只读行为评估、新版实际试用，均未指定模型覆盖。主代理检查生成结果，并执行回归与独立包试验。

这是单轮定性验证，没有无技能对照、多次采样、自动触发率测量或 Windows/Linux 实机运行。旧版评估已经能优先服从用户要求，不能将所有正确行为归因于新版。

## 旧版实际复现

编辑前把完整技能复制到临时目录，在原模块上执行以下检查：

| 场景 | 实际观察 | 修改 |
|---|---|---|
| 在已有中文字体的本机创建带标题画布 | 抛出 `No CJK font found. Try: apt-get install -y fonts-noto-cjk`；用户字体目录未纳入查找 | 补充系统/用户字体目录、跨平台候选及显式字体配置 |
| 自定义浅黄色 `#FFFF99` 卡片 | 文本颜色被选为白色 | 按实际颜色对比选择深色或白字 |
| 1200 宽画布的默认 `strip()` | 位置 x=50，宽仍为 2000 | 整行组件按画布和边距计算宽度 |
| 横条值为 0 或 -5 | 都生成 8 像素正向条 | 零值不画条；负值明确拒绝 |
| 纵柱值为 0 | 仍生成高度 12 的底部色块 | 零值不画柱；小数值不受固定圆角高度放大 |

色彩和尺寸检查临时替换了文字绘制或字体函数，避免字体发现失败遮蔽后续问题。柱形问题先在旧副本执行并打印实际矩形尺寸，再修改实现。

旧版行为评估使用以下三类请求，只阅读技能和实现、查看参考图，没有生成图：

- 英文活动报名流程，1200×675 PNG、紫色、无标题/橙色装饰、保留全画布：评估代理选择显式覆盖标题、颜色与裁剪，但指出中文字体依赖和文档约束。
- 三部门可编辑 SVG：选择原生 SVG，指出“交付 Python 脚本”不能满足矢量编辑；原请求缺少部门细节，代理要求补齐。
- 仅修改 Mermaid 节点名：选择保留源码、不重绘，指出旧版宽泛触发与强制重绘指导冲突。

## 新版独立执行

全部产物创建于隔离临时目录，未写入技能包：

| 请求 | 实际结果 |
|---|---|
| 英文社区活动 `Register -> Confirm -> Attend`，1200×675 紫色 PNG，无标题和强调条 | Pillow + flatkit；尺寸与 PNG 格式核对通过，`trim=False`，`WARN=[]`；子代理和主代理均查看成图，未见截断或重叠 |
| 中文部门交接：运营部整理需求传给设计部，设计部交付视觉稿给执行部，要求可编辑 SVG | 原生 SVG，1200×600，XML 解析通过，6 个文本节点、0 个嵌入图片；主代理用现有 Sharp 渲染后查看，中文标签和连线可见，无明显重叠 |
| 负向控制：`flowchart LR` 中 `A[提交] --> B[审核]`，另有 `style A fill:#eee`；只把“审核”改为“复核” | 返回 Mermaid 源码，只改一个标签，保留 ID、边和样式，没有重绘 |

新版 SVG 请求补齐了旧版评估中缺失的部门信息，因此不是完全相同输入的受控比较。SVG 的系统预览调用失败，浏览器也未打开本地文件；主代理改用已有 Sharp 作本地格式转换。没有在矢量编辑软件中实际拖动或编辑对象，结构检查与预览不代表所有编辑器兼容。

## 自动检查与包独立性

- `uv run scripts/validate_skills.py`：5 个技能的元数据、技能内链接与 Python 语法通过。
- 最后复跑时，默认 uv 缓存写入受沙箱限制；尝试临时缓存和随附 Python 时又发现该解释器没有 PyYAML。随后定位并直接复用首次 uv 运行已建好的校验环境，执行同一个 `scripts/validate_skills.py`，5 个技能再次通过；未下载依赖或申请扩大权限。
- `test_flatkit.py`：8 项通过，覆盖字体发现、显式字体及缓存、自定义浅色文字、窄画布整行组件、固定尺寸与自定义背景裁剪、零值、负值、小数值比例。
- 初次测试误把同一个 TTC 文件等同于同一个字重，实际该集合含 Regular/Bold。修正测试为检查两种字重均使用指定文件，不改变正常的字重选择行为；随后 8 项通过。
- 将仅含技能包的副本复制到临时位置，从另一个工作目录运行 `references/toolkit.md` 中的完整快速示例，得到 1200×675 PNG，`WARN=[]`；没有使用兄弟技能或仓库文档。
- 旧例中的架构、指标、时序、表格和参考复刻均实际渲染，`WARN=[]`，并逐图查看。指标例原来的 1800 高画布裁掉了已有页脚，增加示例画布高度后重新渲染检查。这些旧内容现已由下述虚构样例取代。
- `git diff --check` 通过；另检查了本次范围内未跟踪文本文件的尾随空白和 Python 语法。

字体宽度测试不能检测缺字，已另查看中文和英文实际渲染。未做所有语言、品牌配色、复杂统计图、PPT 或交互网页的端到端测试；包内 PNG 工具也不宣称支持这些格式的原生编辑。

## 文件与复跑

安装包保留通用说明、按需参考、PNG 工具和虚构场景样张。首次整理曾保留旧图片快照；用户指出其中含有项目材料后，已重写全部样例脚本并替换图片，不再保留旧快照。当前脚本及成图位于 `evals/flat-diagram-style/examples/`，脚本要求显式输出目录。

在仓库根目录可复跑：

```bash
uv run scripts/validate_skills.py
uv run --with pillow python evals/flat-diagram-style/test_flatkit.py
uv run --with pillow python evals/flat-diagram-style/examples/gallery.py /tmp/flat-diagram-gallery
uv run --with pillow python evals/flat-diagram-style/examples/reference_replica.py /tmp/flat-diagram-gallery
```

本轮实际使用随附 Python 执行后三个脚本；上面的 uv 命令是等效复跑方式，未额外重复建立 uv 环境。

首次执行创建的旧技能副本、旧图重绘和独立包测试目录已在样例隐私修订中删除。另一个独立行为试用目录只含通用报名流程和部门交接内容。

本次只维护仓库源码，没有同步或覆盖用户级已安装技能。

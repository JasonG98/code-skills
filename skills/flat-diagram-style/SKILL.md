# 扁平图解风格

用纯色图形、清晰层级、统一间距和克制的强调色，让关系与信息容易阅读。**风格与绘图工具分离**：语言、领域、画布比例、颜色和文件格式由任务决定。

## 先选交付方式

沿用用户已给的内容、受众、语言、媒介和编辑要求。信息足够就直接画；仅在关系、数据或交付要求缺失且影响结果时提问。未指定时，普通文档配图可用白底 PNG；标题、图例和尺寸按内容决定。

| 需求 | 实现方式 |
|---|---|
| 静态 PNG 配图 | 可用包内 [flatkit.py](scripts/flatkit.py)，先读 [工具说明](references/toolkit.md) |
| 可编辑 SVG | 使用原生形状、连线和文本节点；不要把 PNG 包进 SVG 冒充矢量 |
| PPT 中逐项编辑 | 使用幻灯片原生形状与文本；可重跑的 Python 脚本不等于形状可编辑 |
| 现有 Mermaid、draw.io 或其他源文件 | 保留原格式与图的语义，只在请求范围内调整样式或内容 |
| 交互图解或网页 | 在已有网页栈中应用视觉原则，不强制转成图片 |
| 精确统计图、密集数据 | 使用合适的图表工具，保留刻度、单位、误差等信息，再调整配色和排版 |

包内工具只负责栅格绘图，不实现上述所有格式。无需为了风格切换用户选定的工具或安装其他技能。

## 视觉约定

- **版式随内容变化**：流程强调顺序，架构强调边界，对比强调同一维度，时间线强调先后。横向、纵向、网格均可。需要代码构图时再读 [图型配方](references/recipes.md)。
- **按实际尺寸布局**：从目标宽高、边距、节点数量计算可用空间；等宽节点使用 `w = (内容宽 − gap × (n−1)) / n`。纵向位置从上一块底部累加。密集内容先分组、换向或拆图，避免一味缩字。
- **建立文字层级**：标题、节点名、说明有清晰字号差异，使用覆盖目标语言的字体。按文字实际宽度断行，保留专有名词；不要把中文字数限制套到其他语言。最终放入文档或缩到展示尺寸后仍应可读。
- **纯色与适量留白**：默认圆角块、浅色分组容器、简洁连线。阴影、装饰图标和强调条只在有助于阅读时加入。标题、副标题、小节和橙色竖条都是可选项。
- **颜色表达稳定角色**：同一组图里同一角色使用相同颜色。通常一个主色、一个辅助色和少量强调已足够；用户品牌色优先。按背景亮度选择文字颜色，同时用标签、线型或形状表达区别。
- **连线表达真实关系**：明确方向和标签，尽量少交叉；不要为了整齐把并列关系画成因果流程。虚线的含义由图例或上下文定义，不固定等同于“返回”。

无既定配色时可用以下默认值；它们不是必须遵守的品牌规范。

| 角色 | 默认色 |
|---|---|
| 主体 | 深蓝 `#1F3A5F` |
| 辅助 | 青绿 `#2A9D8F` |
| 中性 | 灰蓝 `#5A6B82` |
| 强调 | 琥珀 `#E8A33D` |
| 问题 | 珊瑚 `#D9604C` |
| 正文 / 浅底 | `#1F2D3D` / `#F2F4F7` |

需要对照默认视觉时查看 [虚构场景样张](assets/reference-style.png)，只参考层级、形状和间距，不复用样张中的领域、数据或结论。用户提供参考图时，以用户参考为准。

## 内容与准确性

- 用于技能分发的样例使用独立编写的虚构场景与数据，并在图中标明“虚构示例”；不直接复用用户项目材料作为样例。
- 说明图用描述性标题即可；有证据支持结论时再用结论式标题，不要求带数字或表达“提升”。
- 数值、单位、时间范围、来源与比较口径来自用户材料；明确区分实测、目标和示例。缺失信息按任务需要省略、标注“待确认”或询问，不填造假的改善幅度。
- 数值决定长度或面积时，保持相同基线和比例；零值、负值不能画成正数。不同单位、周期或统计口径不能只为整齐就直接比较。
- 照片、截图、实验热力图等证据保留原始含义；需要时在旁边加结构示意，不用装饰图替代证据。

## 检查与交付

1. 检查关系方向、标签和数据是否忠实于材料；在用户要求的尺寸或比例上排版。
2. 导出后用当前环境可用的预览方式检查文字缺字、截断、重叠、对齐、箭头和留白。代码告警不能代替视觉检查；无法预览时说明未验证的部分。
3. 检查文件格式、像素尺寸或页面比例；固定尺寸输出关闭自动裁剪。可编辑交付应保留原生对象及文字。
4. 保存到用户指定目录或当前工作区的合适输出目录，用可访问链接交付。按用户编辑需求提供源文件；提及尚未确认的数据和实际的格式限制。

使用本技能不依赖特定的 `view`、`present_files`、绝对输出目录或系统包管理器。
